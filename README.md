# SolarIQ Egypt ☀️

AI-powered solar site selection platform that analyzes historical weather and air quality data to identify the most optimal locations for solar energy investments in Egypt.

## 🚀 Key Features
- Solar Site Scoring Model based on 6 scientific factors
- Data pipeline (ETL) using Python, Pandas, and SQL
- Integration of NASA POWER & Air Quality APIs
- 30+ Power BI dashboards for insights and decision-making
- AI-powered recommendations and chatbot (planned)

## 📊 Data Sources
- NASA POWER API (Weather & Solar Radiation)
- Open-Meteo / Air Pollution APIs
- Historical climate datasets

## 🧠 Tech Stack
- Python (Pandas, NumPy)
- SQL Server
- Power BI
- Azure (Data Lake, Azure SQL)
- Streamlit (for AI interface)
- OpenAI / LLMs (for chatbot & insights)

## 🏗️ Architecture
Bronze → Raw Data  
Silver → Cleaned Data  
Gold → Aggregated & Scored Data  

## 🎯 Goal
Help governments, investors, and companies make data-driven decisions for solar energy investments.
